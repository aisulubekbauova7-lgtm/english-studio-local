# English Studio

Полностью автономный сайт для изучения английского языка. Не использует серверы, аккаунты, API, базы данных, подписки или внешние ресурсы.

## Запуск

Самый простой способ — дважды щёлкнуть `index.html`: сайт откроется в браузере и будет работать без интернета.

При необходимости его можно запустить через любой простой локальный статический сервер, указав корневой папкой эту папку проекта. Никакой сборки или установки зависимостей не требуется.

## Структура

- `index.html` — главная страница и оболочка приложения.
- `css/styles.css` — адаптивный интерфейс и стили урока.
- `js/app.js` — поиск, навигация, тесты и проверка ответов.
- `topics/topics.js` — вся учебная база в локальном JavaScript-файле.
- `assets/` — место для будущих локальных изображений, аудио или PDF.

## Как добавить тему

В `topics/topics.js` добавьте ещё один вызов `topic(...)` в массив `TOPICS`. Каждая тема содержит:

1. название, категорию и варианты для поиска;
2. краткое объяснение, правило и формулу;
3. таблицу и примеры;
4. два задания с вариантами и правильными ответами.

После сохранения новая тема сама появится в каталоге, фильтрах, поиске, мини-тестах и блоке рекомендаций урока.
